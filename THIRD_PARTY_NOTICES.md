# Third-party components

QuickDrop includes adapted **Magnet** component from
[React Bits](https://github.com/DavidHDev/react-bits), by David Haz.

Source revision: `3a1c7f2f9f94ed833934ab5c2635760b9e644583`.

The original MIT + Commons Clause license is preserved in
[`client/src/components/react-bits/LICENSE.md`](client/src/components/react-bits/LICENSE.md).
The component is used as part of this application, not distributed as a component library.
Local adaptations use the existing Framer Motion dependency and support paused motion,
reduced-motion preferences, and pointer capability checks.

Visual direction draws inspiration from [Buttermax](https://buttermax.net/).
QuickDrop's branding, Three.js sculpture, page composition, and text are original;
no Buttermax imagery, fonts, or source code is included.

The original 3D scene uses [Three.js](https://threejs.org/), distributed under the MIT license. Fonts are Space Grotesk and Instrument Serif, bundled through Fontsource under the SIL Open Font License.
